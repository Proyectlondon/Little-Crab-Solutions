Ejercicio guiado: Construcción completa del Agente de Intake

Tiempo estimado: 4-6 horas. Nivel: Avanzado (integra M01-M06).

Prerrequisitos (deben estar listos de módulos anteriores)

  • Entorno Railway/Render desplegado (M06) con n8n + Ollama + OpenWebUI
  • Notion Integration Token + Database ID para tickets
  • Discord Webhook URL para canal #intakes
  • Deepgram API Key para TTS Gloria
  • LangSmith API Key para tracing
  • Google Forms creado con campos del brief

  1. Paso 1: Google Forms → n8n Webhook

    Form campos: Nombre, Email, Empresa, Problema, Objetivo, Stack actual, Presupuesto, Timeline, Contacto preferido.

    Apps Script en Forms → POST a https://tu-dominio.com/webhook/intake

  2. Paso 2: Workflow n8n "Agente Intake"

    Nodos en secuencia:

    1. Webhook /webhook/intake
    2. Set: Normalizar campos, agregar timestamp, UUID
    3. HTTP Request → Ollama con system prompt (arriba) + brief como user message
    4. Function: Parsear JSON respuesta, validar esquema, separar notion_payload y discord_message
    5. Notion: Create Page en database Intakes con notion_payload
    6. HTTP Request → Deepgram TTS con texto: discord_message → modelo aura-hera-es
    7. Discord: Send Message con embed + archivo audio (multipart)
    8. Google Sheets: Append log histórico (opcional)

  3. Paso 3: Credenciales en n8n (Production)

    En n8n UI → Credentials → crear:

    • Notion API: Integration Token (secret)
    • Discord Webhook: URL (secret)
    • Deepgram API: API Key (secret)
    • LangSmith: API Key (secret) — ya en env vars

    Asignar cada credencial a su nodo correspondiente.

  4. Paso 4: Error Handling + Observabilidad

    Añadir Error Trigger workflow que poste a Discord #alertas con {{ $error.workflow.name }}: {{ $error.message }}.

    Verificar trazas en LangSmith: project "learning-path-prod".

  5. Paso 5: Test End-to-End

    Envía form de prueba → verifica:

    • Página creada en Notion con plan estructurado
    • Mensaje en Discord con embed + audio Gloria reproducible
    • Trazas completas en LangSmith (< 10s latencia total)

  6. Paso 6: Video Demo (Hyperframes + Gloria)

    Guión 60s vertical (9:16):

    1. 0-5s: Hook — "De brief a plan automático en 60 segundos"
    2. 5-15s: Muestra Form → Submit
    3. 15-35s: n8n workflow corriendo (sped up), Notion página apareciendo
    4. 35-50s: Discord notificación + audio Gloria "Nuevo intake de Acme Corp..."
    5. 50-60s: CTA — "¿Quieres automatizar tu intake? Agenda diagnóstico" + logo Little Crab

    Generar con hyperframe_text_to_video + TTS Gloria + subtítulos .vtt.

  7. Paso 7: Documentación en Notion + Repo Git

    Notion page "Agente Intake — Runbook": arquitectura, prompts, credenciales (referencia), troubleshooting, rollback.

    Repo Git: docker-compose.prod.yml, workflows/agente-intake.json, prompts/system-intake.md, scripts/, README.md.
