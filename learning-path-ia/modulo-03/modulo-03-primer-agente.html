Construcción de tu Primer Agente

Pattern "Prompt-to-Action" con OpenWebUI + n8n. Agente que clasifica y responde leads de WhatsApp.

Paso 3 de 7

// objetivos

Qué vas a lograr

  • Diseñar system prompt para clasificación + respuesta automática
  • Crear workflow n8n que reciba webhook de WhatsApp → LLM → respuesta
  • Implementar pattern Prompt-to-Action: prompt estructurado → JSON → acción
  • Manejar estado de conversación (memoria simple con ventana deslizante)
  • Probar end-to-end con webhook real o simulado
// teoría

Conceptos clave

Pattern Prompt-to-Action

El LLM no solo responde texto — devuelve JSON estructurado que el workflow n8n ejecuta como acción.

// Output del LLM (forzado por system prompt)
{
  "accion": "responder_whatsapp",
  "payload": { "mensaje": "¡Hola! Gracias por contactarnos..." },
  "metadata": { "lead_score": 85, "categoria": "venta" }
}

System Prompt para Agente WhatsApp

Claves: rol claro, categorías definidas, formato JSON estricto, ejemplos few-shot.

Memoria de conversación (ventana deslizante)

n8n no tiene memoria nativa → guardamos últimos N mensajes en variable de workflow o Redis. Contexto: system prompt + últimos 5-10 intercambios.

WhatsApp Business API (visión general)

Webhook recibe mensaje → n8n procesa → responde vía API. Para testing: ngrok + webhook local o sandbox de Meta.

// práctica

Ejercicio guiado: Agente WhatsApp Lead-Gen

Tiempo estimado: 2-3 horas. Nivel: Intermedio.

Antes de empezar

  • Entorno M02 funcionando (n8n + Ollama + OpenWebUI)
  • Cuenta Meta Developer (para WhatsApp Business API) o usa webhook.test para simular
  • ngrok instalado (ngrok http 5678)

  1. Paso 1: Crear System Prompt en OpenWebUI

    En OpenWebUI → Configuración → Modelos → System Prompts → Nuevo:

    Eres un agente de calificación de leads para WhatsApp Business.
Tu trabajo: analizar el mensaje entrante y devolver SOLO JSON válido.

CATEGORÍAS:
- "venta": Quiere comprar, pide precio, demo, info comercial
- "soporte": Tiene problema técnico, error, duda de uso
- "spam": Promociones, irrelevante, bots
- "otro": No encaja arriba

FORMATO DE SALIDA (OBLIGATORIO):
{
  "categoria": "venta|soporte|spam|otro",
  "confianza": 0-100,
  "respuesta_sugerida": "Texto listo para enviar al usuario",
  "accion_requerida": "notificar_equipo|responder_auto|ignorar|escalar_humano",
  "lead_score": 0-100,
  "datos_extraidos": { "nombre": "", "empresa": "", "producto_interes": "" }
}

EJEMPLOS:
Input: "Hola, vi su anuncio de agentes IA. Quiero saber precios para mi empresa de 50 personas."
Output: { "categoria": "venta", "confianza": 95, "respuesta_sugerida": "¡Hola! Gracias por tu interés...", "accion_requerida": "notificar_equipo", "lead_score": 90, "datos_extraidos": { "empresa": "50 personas", "producto_interes": "agentes IA" } }

Input: "La app me da error 500 al subir archivo"
Output: { "categoria": "soporte", "confianza": 98, "respuesta_sugerida": "Disculpa el inconveniente...", "accion_requerida": "escalar_humano", "lead_score": 10, "datos_extraidos": {} }

  2. Paso 2: Workflow n8n — Webhook WhatsApp

    En n8n, crea workflow "Agente WhatsApp Lead-Gen":

    1. Webhook node: Path /webhook/whatsapp, Method POST
    2. Set node: Extraer mensaje = {{ $json.body.message }}, telefono = {{ $json.body.from }}
    3. HTTP Request a Ollama (http://ollama:11434/api/chat):
      Body: system prompt (arriba) + user message en array messages
    4. Function node: Parsear JSON respuesta del LLM, validar esquema
    5. IF node: Ramificar por accion_requerida
    6. HTTP Request (ramas): Responder WhatsApp API / Notificar Slack/Email / Log

  3. Paso 3: Exponer webhook con ngrok

    ngrok http 5678

    Copia la URL HTTPS (ej. https://abc123.ngrok-free.app/webhook/whatsapp) y configúrala en Meta Developer Console o usa webhook.site para testing.

  4. Paso 4: Test end-to-end

    Envía POST al webhook:

    curl -X POST https://TU_NGROK.ngrok-free.app/webhook/whatsapp \
  -H "Content-Type: application/json" \
  -d '{"body": {"message": "Hola, quiero info de precios para 20 usuarios", "from": "573001234567"}}'

    Verifica en n8n: execution log → JSON parsed → respuesta enviada.

  5. Paso 5: Memoria simple (opcional, +30 min)

    En n8n, usa Workflow Static Data o variable global para guardar últimos 5 mensajes por telefono. Inclúyelos en el prompt como historial.
