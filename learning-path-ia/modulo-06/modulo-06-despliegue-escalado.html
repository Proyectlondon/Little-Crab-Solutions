Conceptos clave

Local → Cloud: misma compose, distinta config

docker-compose.yml (dev) vs docker-compose.prod.yml (prod). Diferencias: recursos, healthchecks, restart policies, logging, secrets externos.

// práctica

Ejercicio guiado: Deploy a Railway con dominio custom

Tiempo estimado: 60-90 min. Nivel: Intermedio.

Antes de empezar

  • Cuenta Railway (railway.app) o Render (render.com)
  • Dominio propio (opcional, pueden usar subdominio railway.app/render.com)
  • Repo Git con docker-compose.yml + workflows exportados
  • Deepgram API key (para TTS Gloria) - free tier disponible

  1. Paso 1: Crear docker-compose.prod.yml

    version: '3.8'
services:
  ollama:
    image: ollama/ollama:latest
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    deploy:
      resources:
        limits:
          memory: 6G
        reservations:
          devices:
            - driver: nvidia
              count: 1
              capabilities: [gpu]
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:11434/api/tags"]
      interval: 30s
      timeout: 10s
      retries: 3
    restart: unless-stopped

  n8n:
    image: n8nio/n8n:latest
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD={{N8N_PASSWORD}}
      - N8N_HOST=0.0.0.0
      - N8N_PORT=5678
      - N8N_PROTOCOL=https
      - WEBHOOK_URL={{WEBHOOK_URL}}
      - GENERIC_TIMEZONE=America/Bogota
      - LANGCHAIN_TRACING_V2=true
      - LANGCHAIN_API_KEY={{LANGCHAIN_API_KEY}}
      - LANGCHAIN_PROJECT=learning-path-prod
    volumes:
      - n8n_data:/home/node/.n8n
    depends_on:
      ollama:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:5678/healthz"]
      interval: 30s
      timeout: 10s
      retries: 3
    restart: unless-stopped

  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    ports:
      - "3000:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
      - WEBUI_SECRET_KEY={{WEBUI_SECRET}}
    volumes:
      - openwebui_data:/app/backend/data
    depends_on:
      ollama:
        condition: service_healthy
    restart: unless-stopped

volumes:
  ollama_data:
  n8n_data:
  openwebui_data:

  2. Paso 2: Conectar repo a Railway

    1. Railway → New Project → Deploy from GitHub
    2. Selecciona repo → Railway detecta docker-compose.yml
    3. En Variables: añade todas las de .env.production (marca como Secret las sensibles)
    4. Deploy → espera build + healthchecks

  3. Paso 3: Dominio custom + SSL

    En Railway: Settings → Domains → Custom Domain → añade agentes.tudominio.com.

    Configura CNAME en tu DNS apuntando a xxx.up.railway.app. SSL automático en minutos.

  4. Paso 4: Probar endpoint TTS (Gloria) en n8n

    En n8n production, crea workflow "TTS Gloria":

    1. Webhook /webhook/tts
    2. HTTP Request a Deepgram: 
      POST https://api.deepgram.com/v1/speak?model=aura-hera-es
Headers: Authorization: Bearer {{DEEPGRAM_API_KEY}}, Content-Type: application/json
Body: { "text": "Hola, esto es Gloria hablando desde Deepgram" }
    3. Respuesta: audio/mpeg → devolver como binary o subir a storage

  5. Paso 5: Health checks y rollback

    Verifica en Railway: Metrics → CPU/RAM/Network. Logs → sin errores.

    Rollback: Deployments → Previous → Rollback (1 click).
