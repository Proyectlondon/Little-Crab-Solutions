Conceptos clave

¿Por qué observabilidad en agentes?

Los agentes son sistemas no deterministas. Sin visibilidad: no sabes si fallan, cuánto cuestan, ni por qué alucinan. Observabilidad = confianza para poner en producción.

Métricas obligatorias (Golden Signals para agentes)

  • Latencia: P50, P95, P99 end-to-end (webhook → respuesta)
  • Costo: USD por ejecución (input/output tokens × precio modelo)
  • Tasa de error: % ejecuciones con error / timeout / alucinación detectada
  • Token usage: input + output por llamada, tendencia temporal
  • Calidad: Evaluadores automáticos (correctitud, tono, formato JSON válido)

Trazas (Traces) en LangSmith

Una traza = una ejecución completa. Contiene: spans (pasos), inputs/outputs, latencia, tokens, errores, metadata (usuario, sesión, versión prompt).

// práctica

Ejercicio guiado: Observabilidad end-to-end con LangSmith

Tiempo estimado: 90-120 min. Nivel: Intermedio.

Antes de empezar

  • Cuenta LangSmith (smith.langchain.com) o W&B (wandb.ai)
  • API Key generada
  • Workflow M03 o M04 funcionando para instrumentar
  • Variable de entorno LANGCHAIN_API_KEY en n8n

  1. Paso 1: Configurar LangSmith en n8n

    En Docker Compose (M02), añade a servicio n8n:

    environment:
  - LANGCHAIN_TRACING_V2=true
  - LANGCHAIN_API_KEY=${LANGCHAIN_API_KEY}
  - LANGCHAIN_PROJECT=learning-path-agents
  - LANGCHAIN_ENDPOINT=https://api.smith.langchain.com

    Reinicia: docker compose up -d --force-recreate n8n

  2. Paso 2: Instrumentar llamada a Ollama

    En el workflow del agente (M03), el nodo HTTP Request a Ollama ya genera trazas automáticas si LangSmith detecta patrón OpenAI-compatible.

    Para trazas custom, usa Function node que llama a fetch('https://api.smith.langchain.com/v1/runs', ...) o SDK si migras a código.

  3. Paso 3: Ver trazas en LangSmith UI

    Ejecuta el agente 3-5 veces → ve a smith.langchain.com → Projects → learning-path-agents.

    Verifica: spans por nodo, latencia total, tokens, input/output de cada paso.

  4. Paso 4: Crear Dataset de evaluación

    En LangSmith: Datasets → New → "whatsapp-leads-test".

    Añade 10 ejemplos: input (mensaje) + expected output (categoria, lead_score rango).

  5. Paso 5: Ejecutar Evaluación (Evaluation)

    LangSmith → Evaluations → New → selecciona dataset + tu agente (via API/webhook).

    Evaluadores: "Exact match" para categoria, "Score range" para lead_score, "JSON valid" para formato.

  6. Paso 6: Alertas y Dashboard

    En LangSmith: Monitors → New Monitor:

    • Métrica: latency_p95 > 10s → Alert to Slack webhook
    • Métrica: error_rate > 5% → Alert to Slack
    • Métrica: cost_per_run > $0.10 → Alert to Email
