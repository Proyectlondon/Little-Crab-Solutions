Stack Técnico Básico

Configura tu entorno local: n8n, Ollama, Docker y Git. Base técnica para todos los módulos siguientes.

Paso 2 de 7

// objetivos

Qué vas a lograr

  • Instalar y configurar n8n local con Docker Compose
  • Levantar Ollama y descargar modelos (Qwen 2.5, Llama 3.1)
  • Conectar n8n ↔ Ollama vía API compatible OpenAI
  • Inicializar repo Git y configurar flujo de commits básicos
  • Validar entorno ejecutando un workflow n8n que llama a Ollama
// teoría

Conceptos clave

¿Por qué local-first?

Control total sobre datos, costos predecibles (0 $/mes en inferencia), latencia mínima, funcionamiento offline. Ideal para prototipar y aprender.

n8n — Orquestación visual

Editor de nodos para flujos: triggers (webhook, cron, form), transformaciones, llamadas HTTP, integraciones (Sheets, Slack, Telegram, Notion). Self-hosted con Docker.

Ollama — LLMs locales

Runtime que sirve modelos (Llama, Qwen, Gemma, etc.) con API compatible OpenAI. Gestión de modelos, cuantización, GPU/CPU automático.

Docker Compose — Entorno reproducible

Un archivo docker-compose.yml levanta n8n, Ollama, OpenWebUI, Postgres (para n8n) con un comando. Versionable, portable, igual en dev/prod.

Git — Versionado desde día 1

Commits atómicos, mensajes convencionales (feat:, fix:, docs:), ramas por feature. Base para CI/CD futuro.

// práctica

Ejercicio guiado: Entorno local completo

Tiempo estimado: 60-90 min. Nivel: Principiante.

Antes de empezar

  • Docker Desktop instalado y corriendo
  • Git instalado (git --version)
  • Editor de código (VS Code recomendado)
  • 8 GB RAM mínimo (16 GB recomendado para modelos 7B+)

  1. Paso 1: Clonar plantilla y crear docker-compose.yml

    Crea una carpeta learning-path-env y añade este docker-compose.yml:

    version: '3.8'
services:
  ollama:
    image: ollama/ollama:latest
    ports:
      - "11434:11434"
    volumes:
      - ollama_data:/root/.ollama
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]

  n8n:
    image: n8nio/n8n:latest
    ports:
      - "5678:5678"
    environment:
      - N8N_BASIC_AUTH_ACTIVE=true
      - N8N_BASIC_AUTH_USER=admin
      - N8N_BASIC_AUTH_PASSWORD=changeme
      - N8N_HOST=localhost
      - N8N_PORT=5678
      - N8N_PROTOCOL=http
      - WEBHOOK_URL=http://localhost:5678/
      - GENERIC_TIMEZONE=America/Bogota
    volumes:
      - n8n_data:/home/node/.n8n
    depends_on:
      - ollama

  open-webui:
    image: ghcr.io/open-webui/open-webui:main
    ports:
      - "3000:8080"
    environment:
      - OLLAMA_BASE_URL=http://ollama:11434
      - WEBUI_SECRET_KEY=changeme
    volumes:
      - openwebui_data:/app/backend/data
    depends_on:
      - ollama

volumes:
  ollama_data:
  n8n_data:
  openwebui_data:

  2. Paso 2: Levantar servicios

    En la carpeta del proyecto:

    docker compose up -d

    Nota: Primera vez descarga imágenes (~2-3 GB). Espera a que docker compose ps muestre todo healthy o Up.

  3. Paso 3: Verificar Ollama y descargar modelo

    En otra terminal:

    # Verificar API
curl http://localhost:11434/api/tags

# Descargar modelo ligero (4.7 GB)
docker exec -it learning-path-env-ollama-1 ollama pull qwen2.5:7b

# O modelo más capaz (4.7 GB)
docker exec -it learning-path-env-ollama-1 ollama pull llama3.1:8b

  4. Paso 4: Acceder a n8n y OpenWebUI

    • n8n: http://localhost:5678 (user: admin, pass: changeme)
    • OpenWebUI: http://localhost:3000 (crea cuenta admin)

  5. Paso 5: Conectar n8n → Ollama

    En n8n, crea un workflow:

    1. Añade nodo HTTP Request
    2. URL: http://ollama:11434/api/chat (Docker DNS) o http://host.docker.internal:11434/api/chat
    3. Method: POST
    4. Headers: Content-Type: application/json
    5. Body (JSON): 
      {
  "model": "qwen2.5:7b",
  "messages": [{ "role": "user", "content": "Di hola en 10 palabras" }],
  "stream": false
}
    6. Ejecuta y verifica respuesta

  6. Paso 6: Inicializar Git

    git init
git add docker-compose.yml
git commit -m "feat: add docker-compose for n8n + ollama + open-webui"
git branch -M main
