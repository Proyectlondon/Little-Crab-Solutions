Automatización de Flujos con n8n

Google Forms → Clasificación automática → Notificaciones Slack/Telegram. Credenciales seguras, versionado Git, manejo de errores.

Paso 4 de 7

// objetivos

Qué vas a lograr

  • Crear formulario Google Forms conectado a n8n vía webhook
  • Clasificar respuestas con LLM (Ollama) o reglas deterministas
  • Enrutar notificaciones a Slack, Telegram, Email según categoría
  • Gestionar credenciales de forma segura (n8n credentials, variables de entorno)
  • Versionar workflows con Git (export JSON, commits semánticos)
  • Implementar retry/error handling para flujos robustos
// teoría

Conceptos clave

Arquitectura del flujo

Google Forms → Webhook n8n → [Clasificar: LLM o Reglas] → Router → 
  ├─ Slack (ventas)
  ├─ Telegram (soporte)
  ├─ Email (admin)
  └─ Sheets (log histórico)

Credenciales en n8n

  • n8n Credentials UI: Encriptadas en BD, reutilizables, separadas del workflow JSON
  • Variables de entorno: Para keys de API en Docker (N8N_ENCRYPTION_KEY)
  • NO hardcodear tokens en nodos Function ni HTTP Request

Versionado de workflows

Exportar workflow → JSON → commit a Git. Permite: history, rollback, code review, CI/CD futuro.

# En n8n UI: Workflow → Export → workflow.json
git add workflows/automatizacion-forms.json
git commit -m "feat: add forms classification workflow with slack/telegram routing"

Manejo de errores (Error Trigger)

Nodo Error Trigger captura fallos → notifica a canal #alertas → reintento automático (configurable) → dead letter queue si persiste.

// práctica

Ejercicio guiado: Pipeline Forms → Clasificación → Notificaciones

Tiempo estimado: 2-3 horas. Nivel: Intermedio.

Antes de empezar

  • Entorno M02/M03 funcionando (n8n + Ollama)
  • Cuenta Google (Forms + Sheets)
  • Workspace Slack (o usa webhook.site para testing)
  • Bot Telegram creado (@BotFather)

  1. Paso 1: Google Forms + Webhook

    Crea Form con campos: Nombre, Email, Empresa, Tipo consulta (venta/soporte/otro), Mensaje.

    En n8n: Webhook node → Path /webhook/forms-lead → Method POST

    En Forms: Configuración → Scripts → Apps Script para POST a webhook n8n (ver recursos)

  2. Paso 2: Nodo de Clasificación (LLM o Reglas)

    Opción A — Reglas deterministas (rápido, gratis):

    // Function node
const tipo = $json["Tipo consulta"];
if (tipo === "venta") return [{...$json, ruta: "slack-ventas"}];
if (tipo === "soporte") return [{...$json, ruta: "telegram-soporte"}];
return [{...$json, ruta: "email-admin"}];

    Opción B — LLM (Ollama) para clasificación semántica:

    HTTP Request a http://ollama:11434/api/chat con system prompt de clasificación → parse JSON → router.

  3. Paso 3: Credenciales Slack y Telegram

    En n8n → Credentials → New:

    • Slack API: Bot Token (xoxb-...) → scopes: chat:write, channels:read
    • Telegram API: Bot Token (de @BotFather)

  4. Paso 4: Nodos de Notificación + Router

    Switch node (ruta) → 3 ramas:

    1. Slack: Post message a #leads-ventas con bloques formateados
    2. Telegram: Send message a chat_id de soporte
    3. Email (Send Email node): Resumen a admin

  5. Paso 5: Error Handling + Log a Sheets

    Añade nodo Google Sheets (Append) en cada rama para log histórico.

    Añade Error Trigger workflow aparte: Webhook → Slack #alertas-n8n con {{ $error.message }}.

  6. Paso 6: Exportar y versionar

    # En n8n: Workflow → Export → guardar en workflows/forms-automation.json
git add workflows/forms-automation.json
git commit -m "feat: add forms → classification → slack/telegram/email pipeline with error handling"
